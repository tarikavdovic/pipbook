# Pipbook

Pipbook is a personal trading journal for forex traders who want to learn from their own decisions. Traders log every trade with its setup, entry, stop loss, take profit, result and a chart screenshot, and review their statistics to see which setups work and which do not.

## Run the project

```
npm install
npx expo start
```

Scan the QR code with Expo Go (SDK 58).

## Features

- [x] List of trades (mock data)
- [x] Trade details component
- [ ] Trade details screen
- [ ] Add and edit trades with validation
- [ ] Tabs for Trades, Stats and Profile
- [ ] Chart screenshot from the camera or gallery
- [ ] Settings saved on the device
- [ ] Login and trades stored in Supabase
- [ ] Stats: win rate, total R, best pair
- [ ] Android build (APK)
